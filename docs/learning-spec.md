# Learning specification

## Invariants

- 解答を見る前に能動的な回答を求める。
- 誤答は同一セッション内と、後日のセッションで再確認する。
- 正解でも反応が遅い問題は、一度で定着と判定しない。
- 新規・既習・苦手問題を混ぜる。
- 定着は異なる日の成功を含む複数回の想起で判定する。
- フィードバックは正答と式の意味を示し、罰点を与えない。

## Core metrics

- 初回回答の正答率
- 正答までの反応時間中央値
- 翌日・3日後・7日後の初回正答率
- 誤答問題の再誤答率
- 81問の出題率・定着率
- セッション完了率と自発的再訪率

# 「九九のにわとり島」ゲーム設計

## 対象と基本方針

- 対象は九九を学び始める小学2年生。1回3〜5分で一区切りにする。
- 1〜9の段を9つの島（章）にし、各島を「たまご → ひよこ → にわとり → チャレンジ」の順で進む。
- 失敗によるライフ、減点、アイテム没収、連続記録の消失は設けない。
- 正解だけでなく、ヒントを使った学習、間違い直し、後日の復習も成長として扱う。
- 回答は画面上の大きな数字パッドで行い、物理キーボードを前提にしない。

## 物語と学習マップ

プレイヤーは案内役のにわとり「コッコ」と、9つの島に散らばった「九九のたまご」を育てる。島を学ぶほど、たまごがひよこ、にわとりへ成長し、島にも花や家が増える。

ホーム画面の文言：

- 見出し：「きょうは どのしまへ いく？」
- 続きから：「つづきから あそぶ」
- 復習導線：「おさらいが まってるよ」
- 島カード：「2のしま」「ひよこまで そだったよ」
- 未開放の段：「まえの しまを そだてると いけるよ」

島は順番どおりでなく選べる。初回は2・5・10のまとまりを想起しやすい段を案内しても、他の島を禁止しない。

## 共通のゲーム進行

1. 島と段階を選ぶ。「2のしま・たまごを はじめる」
2. 目的を一文で伝える。「2こずつの まとまりを みつけよう」
3. 6〜10問を解く。残り時間ではなく「あと 3もん」を表示する。
4. 誤答は説明後、2〜4問あけて形を変えて再出題する。
5. 結果画面で成長と次の一歩を示す。

途中退出時は「ここまでを ほぞんしたよ。また つづきから あそべるよ」とし、確認なしで安全に保存する。

## 4つの習熟段階

### 1. たまご：意味をつかむ

- 目的：同じ数のまとまりと掛け算の式を結びつける。
- 6問、時間制限なし。絵のまとまりを数え、3択または数字パッドで答える。
- 例：「たまごが 3こずつ、4はこ あるよ。ぜんぶで なんこ？」
- 「かぞえてみる」で各まとまりを順に光らせ、「3 + 3 + 3 + 3」と「3 × 4」を表示する。
- 完了条件：全問に取り組み、間違えた問題のやり直しを終える。正答率による足止めはしない。
- 完了文言：「たまごが ぴかぴか！ 2こずつの まとまりが わかったね」

### 2. ひよこ：答えを思い出す

- 目的：絵を常時見ずに、式から答えを取り出す。
- 8問。4つの答えボタンから選ぶ。最初の数問だけ小さな配列図を出し、その後は隠す。
- 例：「3 × 4 は？」／ボタン「7」「12」「14」「16」
- 誤答時：「だいじょうぶ。3こが 4つだよ」と配列図を表示し、「もういちど」を押して答える。
- 選択肢は近い九九の答えを用いるが、同じ誤答を誘導し続けない。
- 完了条件：全問に取り組み、誤答問題を少なくとも1回、自力またはヒント後に正解する。
- 完了文言：「ひよこが うまれた！ おもいだす ちからが そだったよ」

### 3. にわとり：自力で答える

- 目的：順番に頼らず、正確に答える。
- 10問。式を見て画面数字パッド（0〜9・けす・こたえる）で入力する。
- 新しく学ぶ段を約7問、すでに学んだ段を約3問混ぜる。出題順は毎回変える。
- 急かすカウントダウンは置かない。反応時間は適応出題にだけ使い、子どもには競争値として強調しない。
- 未入力時の「こたえる」は無効にし、「すうじを おしてね」と案内する。
- 完了条件：10問とやり直しを完了。初回正答率80%以上ならチャレンジを案内し、未満なら「もういちど れんしゅう」を推奨するが進行は塞がない。
- 完了文言：「にわとりに そだった！ ばらばらの じゅんばんでも できたね」

### 4. チャレンジ：あとでも覚えている

- 目的：時間を空けた検索練習で定着を確かめる。
- にわとり完了の翌日以降に「おすすめ」として表示する。待たずに試すこともできる。
- 10問。通常式6問、穴埋め2問（「4 × □ = 20」）、既習段との混合2問。
- 画面数字パッドで回答し、問題中のヒントは任意。終了後に全問の答えと意味を確認できる。
- 完了条件：初回正答率80%以上かつ全問完了で「おぼえてた羽」を獲得。未達でも段階は失わず、苦手3問までの短いおさらいを提案する。
- 未達文言：「わすれても だいじょうぶ。おもいだすと もっと つよくなるよ」
- 達成文言：「あとでも おぼえてた！ おぼえてた羽を みつけたよ」

## 正誤フィードバック

- 正解：「せいかい！ 3 × 4 = 12」
- 誤答：「おしい！ 3こが 4つ。いっしょに みよう」
- 再挑戦正解：「できた！ おもいだせたね」
- 正誤を色だけで示さず、文言、記号、短い音（設定で無音可）を併用する。
- 正解演出は約0.8秒、成長演出は3秒以内を目安とし、「スキップ」を常に用意する。

## 結果と報酬

結果画面は順位や他人との比較を置かず、自分の学習を可視化する。

- 見出し：「きょうの ぼうけん」
- 指標：「はじめから できた 7もん」「おもいだせた 3もん」
- 苦手への肯定：「むずかしい もんだいを 2つ みつけたよ」
- 主ボタン：「つぎへ すすむ」
- 副ボタン：「もういちど」「しまへ もどる」

報酬は、各段階の成長姿、島の飾り、「がんばり羽」「おぼえてた羽」。プレイ時間や無欠席ではなく、学習完了、誤答の再挑戦、後日の想起に付与する。報酬の取り逃しや消失は設けない。

## 画面数字パッド

- 3列で `1〜9`、最下段を `けす / 0 / こたえる` とする。
- ボタンは最低44 × 44 CSS px、主なスマートフォンでは56px以上を目標にする。
- 入力値は式の直下に大きく表示し、1〜2桁に制限する。
- 「けす」は1文字削除。長押しやスワイプなど、説明が必要な操作を必須にしない。
- 正解後は次問へ自動遷移するが、誤答後は子どもが説明を見て「もういちど」を押すまで進めない。

## レスポンシブとアクセシビリティ

- 320px幅から横スクロールなしで完走できるモバイルファースト設計とする。
- 狭い画面は「進捗 → 式 → 補助図 → 数字パッド」の1列。広い画面は式・補助図と数字パッドの2列にする。
- 縦向きでは数字パッドを画面下部に収め、主要な式と回答値が同時に見えるようにする。
- 横向きでは左右2列にして高さ不足を避ける。固定高さや端末固有の寸法に依存しない。
- 文字はひらがな中心で、式・数値は大きくする。重要操作には文字ラベルを付ける。
- フォーカス表示、読み上げ可能な状態通知、200%文字拡大、`prefers-reduced-motion` に対応する。
- 音、振動、アニメーションは補助に留め、設定で個別に停止できる。

## 3〜5分に収める目安

- 導入10秒、1問12〜18秒、結果20秒を基準にする。
- 誤答が多い場合は問題数を増やさず、最大3問を同セッション内で再出題し、残りは次回の「おさらい」に送る。
- セッション終了後に自動で次ゲームを始めず、続けるか終わるかを子どもが選べるようにする。

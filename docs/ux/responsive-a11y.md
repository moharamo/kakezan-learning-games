# Responsive and accessibility acceptance criteria

- 320px以上の幅、スマートフォン縦横、タブレット、デスクトップに対応する。
- 320×568、390×844、844×390、768×1024、1366×768で確認する。
- 横スクロールを発生させない。
- 主要タッチ領域は44×44 CSS px以上とする。
- タッチ、マウス、キーボードのみの各操作で完走できる。
- 200%文字拡大でも主要操作を欠落させない。
- 正誤は色だけに依存せず、文言やアイコンを併用する。
- フォーカスを常に視認可能にし、論理的な順序にする。
- `prefers-reduced-motion` を尊重する。
- ソフトウェアキーボード表示中も問題と回答欄を確認できるようにする。

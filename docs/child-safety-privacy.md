# 子どもの安全とプライバシー

## MVP方針

- 氏名、誕生日、顔、声、位置情報を収集しない。
- 外部通信、広告、課金、共有、外部リンクを設けない。
- 進捗を保存する場合は端末内（ブラウザのローカルストレージ）に限定し、保護者が消去できるようにする。
- 強い点滅、大音量、時間圧、罰、能力を断定する表示を避ける。
- 子どもがいつでも終了・休憩できる自然な区切りを作る。
- 本ゲームを計算能力の診断ツールとして表示しない。
- 解析は匿名のイベントだけに限定し、個人識別やマーケティング用のユーザーIDは持たない。

## アクセス解析

- GA4 は `index.html` の `window.__GA4_MEASUREMENT_ID__`（測定ID）に値が設定されているときだけ有効にする。
- 送信するイベントは `page_view`、`game_view`、`game_start`、`game_complete` のような匿名イベントに限定する。
- `user_id`、氏名、顔、声、位置情報、端末固有識別子は送信しない。
- `anonymize_ip` を有効にし、広告向けの識別機能は無効にする。
- 測定が未設定の開発環境では、イベントは送信せずにローカルで動作する。

子どもを対象に観察やデータ収集を行う場合は、実施前に保護者同意、停止基準、保存期間、削除方法を別途定める。
